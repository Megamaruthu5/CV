# Single Page CV (HTML Only)

A single-page Curriculum Vitae (CV) built using **only HTML**.  
This project focuses on semantic structure, accessibility, and clean document organization without using CSS or JavaScript.

---

##  Project Objective

The goal of this project is to create a clean and readable CV using only HTML while following best practices such as:

- Semantic HTML structure
- Accessibility-friendly markup
- SEO and Open Graph meta tags
- Simple and clear content layout

The CV layout and content are based on the provided reference design.

---

##Technologies Used

- HTML5 (Semantic HTML only)
- No CSS
- No JavaScript

---

## Features

- Single-page CV layout
- Proper use of semantic HTML elements:
  - `<header>`
  - `<main>`
  - `<section>`
  - `<article>`
  - `<footer>`
- SEO meta tags for search engines
- Open Graph (OG) meta tags for social media sharing
- Favicon support
- Beginner-friendly and easy to extend

---

##  CV Sections Included

- **Header**
  - Name
  - Job title (e.g., Junior Frontend Developer)
  - Address
  - Phone number
  - Email

- **Skills**
  - HTML
  - CSS
  - JavaScript
  - Accessibility
  - Responsive Web Design
  - Technical Writing
  - Presentation

- **Education**
  - School name
  - Location
  - Degree
  - Duration
  - Academic highlights

- **Experience**
  - Company name and location
  - Job title
  - Employment duration
  - List of achievements
  - Skills used or gained

- **Across the Internet**
  - LinkedIn profile
  - GitHub profile
